# fb-clone-website

Facebook Clone (Full-Stack Social Media Application)
A modern, responsive, full-stack social media application inspired by Facebook. Designed with clean architecture, real-time interaction, and modern UI/UX practices.

🚀 Key Features
Authentication & User Management

Secure user sign-up, login, and logout.

JWT (JSON Web Tokens) or session-based authentication.

OAuth integration (e.g., Google or GitHub login).

Password hashing using bcrypt.

News Feed & Posts

Create, edit, and delete text, image, or video posts.

Interactive feed with real-time updates for posts and reactions.

Infinite scrolling or paginated feed loading.

Reactions & Comments

Multi-reaction support (Like, Love, Haha, Wow, Sad, Angry).

Nested comment threads on posts with real-time updates.

Social Connections

Send, accept, decline, or cancel friend requests.

Dedicated pages for friend lists and pending requests.

User feed tailored to friends' posts.

User Profiles & Customization

Personalized profile pages featuring user posts, bio, and details.

Dynamic profile picture and cover photo uploads.

Custom media storage integration (e.g., AWS S3 or Cloudinary).

Messaging & Real-Time Chat

One-on-one instant messaging powered by WebSockets (Socket.io).

Online/offline user status indicators.

UI & Responsive Design

Fully responsive design tailored for mobile, tablet, and desktop views.

Dark Mode and Light Mode theme toggle.

🛠️ Tech Stack
Frontend
Framework: React.js / Next.js

Styling: Tailwind CSS / Styled Components

State Management: Redux Toolkit / React Context API

Icons: Lucide React / FontAwesome

Backend
Runtime: Node.js

Framework: Express.js

Database: MongoDB (Mongoose) or PostgreSQL (Prisma)

Real-time Communication: Socket.io

File Storage: Cloudinary / AWS S3

📦 Getting Started
Prerequisites
Make sure you have the following installed on your local machine:

Node.js (v16.x or higher)

npm or yarn

MongoDB or a running PostgreSQL instance
